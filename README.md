# Deep Juno 🌌

**Deep Juno** は Rust + [Bevy ECS](https://bevyengine.org/) で構築された、CLI ベースの **Tick 駆動型 4X 文明シミュレーションエンジン**です。
グラフィックスを排除し、純粋なシミュレーションロジックとアーキテクチャに焦点を当てています。

---

## 特徴

| 特徴 | 概要 |
|------|------|
| **決定論的シミュレーション** | 乱数シードにより完全再現可能（`seed` × `tick` ハッシュ） |
| **Deep ECS アーキテクチャ** | すべての状態を Component として管理し、System が並列処理 |
| **ヘッドレス高速実行** | `ScheduleRunnerPlugin` によるレンダリング負荷ゼロの超高速 Tick 処理 |
| **ドメインと表示の分離** | `SimulationEvent` でドメインロジックと表示出力を完全分離 |
| **環境とテラフォーミング** | 惑星環境のシミュレーション、資源枯渇、そして居住性を改善するテラフォーミング |
| **高度な国家 AI (v2)** | 性格、記憶、国内派閥を持つ AI による動的な外交と意思決定 |

---

## 実装済みシステム

| # | システム | 内容 |
|---|----------|------|
| 1 | **経済** | 人口規模によるスケールメリット、技術レベルによる産出ボーナス |
| 2 | **人口** | 食料事情に基づく動的な人口増減と飢餓メカニクス |
| 3 | **貿易** | 星間距離と輸送コストを考慮した自動貿易 |
| 4 | **外交** | 時間経過と利害に基づく関係スコア変動 |
| 5 | **戦争** | 関係悪化による自動開戦、艦隊戦、民間人被害、停戦協定 |
| 6 | **技術** | 6系統の自動研究、核融合、レアアース活用、環境技術 |
| 7 | **イベント** | 環境災害、隕石衝突、技術ブレイクスルー等12種類の決定論的イベント |
| 8 | **テラフォーミング** | 大気・気温・水・生物の4フェーズによる惑星環境の根幹的改造 |
| 9 | **国家 AI** | 性格パラメータ、他国への記憶（信頼度）、国内派閥による多角的意思決定 |

## クイックスタート

```bash
# リポジトリをクローン
git clone <repository-url>
cd omni-sim

# インタラクティブ TUI モードで実行 (推奨)
cargo run -- --tui

# 従来の CLI モードで実行
cargo run

# カスタム設定で実行
cargo run -- --tui --max-ticks 100 --seed 123
```

### コマンドラインオプション

| オプション | 説明 | デフォルト |
|-----------|------|-----------|
| `--tui` | インタラクティブな TUI モードで実行 | `false` |
| `--max-ticks <N>` | シミュレーションの最大 Tick 数 | `50` |
| `--seed <N>` | 乱数シード（再現性のため） | `42` |

## 初期世界の構成

シミュレーションは以下の3つの星系・惑星・国家で開始されます:

| 星系 | 惑星 | 国家 | 初期人口 | 特性 |
|------|------|------|---------|------|
| Sol | 地球 | 地球連邦 | 1000万 | バランス型 |
| Alpha Centauri | プロキシマb | ケンタウリ共和国 | 200万 | 鉱物豊富 |
| Sirius | シリウスIII | シリウス帝国 | 500万 | エネルギー豊富 |
