## 外交システムの実装優先度

**Phase 5での実装範囲（QA.mdより）**

### 目標範囲

- 貿易協定や同盟
- 軍事要素も含む（紛争・戦争）
- 簡単なルールベースAI
- 将来的にはLLMとの連携も視野

### 最小限の実装（MVP）

Phase 5で実装:
1. **基本的な友好度システム**
   - -100 〜 +100 のスコア
   - 貿易成功で上昇、失敗で下降

2. **貿易協定**
   - 2国間の貿易量と条件を規定
   - 自動更新または期限付き

3. **同盟システム**
   - 軍事同盟（共同防衛）
   - 経済同盟（関税優遇）

4. **基本的な紛争**
   - 星系の征服
   - 簡易戦闘計算

5. **国家AIの基本行動**
   - ルールベースの意思決定
   - 友好国との貿易拡大
   - 敵対国への対抗措置

### 将来の拡張

Phase 10以降:
1. **複雑な外交イベント**
   - 外交使節の派遣

   - 長期戦略の立案

## 外交関係の初期状態

**ランダム生成 + 地理的要因**

シミュレーション開始時:
- 隣接する国家は初期友好度が高い傾向
- 遠方の国家は中立または未知
- ランダム要素で多様性を確保
- 一部の国家間に事前設定された関係（オプション）

## 国家AIの戦略タイプ

**簡単なルールベースAI（Phase 5）**

### AIタイプ

1. **協力的（Cooperative）**
   - 貿易重視
   - 同盟を積極的に結ぶ
   - 戦争を避ける

2. **競争的（Competitive）**
   - 経済優位を追求
   - 戦略的貿易
   - 必要なら軍事行動

3. **拡張主義（Expansionist）**
   - 領土拡大最優先
   - 積極的な植民と征服
   - 軍事力重視

4. **孤立主義（Isolationist）**
   - 自給自足志向
   - 最小限の外交
   - 防衛重視

5. **日和見主義（Opportunistic）**
   - 状況に応じて行動変化
   - 強者に従い、弱者を攻める
   - 利益最大化
