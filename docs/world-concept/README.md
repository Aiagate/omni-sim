## QA.md との対応

各ドキュメントは [QA.md](../../QA.md) の回答に基づいて作成・更新されています。

主要な決定事項：
- **目的**: ゲームのプロトタイプ/実装
- **プレイヤー**: 完全自動（観察のみ）
- **舞台**: 遠未来の銀河規模（3D空間）
- **スケール**: 最終目標1億星系
- **トーン**: オタク的ロマン優先（科学的厳密性より面白さ）
- **AI**: ルールベース、将来的にLLM連携
