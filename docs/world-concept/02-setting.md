# 世界の設定

## 時代・時期

[要確認: シミュレーションの時代設定]

### 選択肢

1. **現代（21世紀）**: 現実世界の国家間貿易
2. **近未来（22-23世紀）**: 地球圏内の国家・コロニー
3. **遠未来（星間時代）**: 銀河規模の星間国家
4. **架空の世界**: オリジナルのファンタジー/SF設定
5. **時代非依存**: 抽象的な経済シミュレーション

現在の実装ガイドに「銀河規模スケール」という記載があることから、**遠未来（星間時代）**が有力候補と思われますが、確認が必要です。

## 舞台・スケール

[要確認: シミュレーションの舞台]

### 地理的/空間的スケール

#### オプションA: 地球規模
- 舞台: 地球上の国家
- 距離: km単位
- 輸送手段: 船舶、航空機

#### オプションB: 太陽系規模
- 舞台: 惑星間の植民地・国家
- 距離: 天文単位（AU）
- 輸送手段: 宇宙船

#### オプションC: 銀河規模（推定）
- 舞台: 複数の恒星系にまたがる星間国家
- 距離: 光年単位
- 輸送手段: 星間輸送艦隊

#### オプションD: 抽象的な空間
- 舞台: 現実の地理に依存しない抽象的なネットワーク
- 距離: 抽象的な「距離」概念
- 輸送手段: 抽象的な「輸送」
