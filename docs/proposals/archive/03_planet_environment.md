# 提案 3: 惑星環境・居住性シミュレーション

## 概要

現在の惑星は産出量の初期値が異なるだけで、環境それ自体がシミュレーションの要素になっていない。**居住性・大気組成・重力・放射線・気候**といった環境パラメータを導入し、人口キャパシティ・生産効率・テラフォーミングの対象として惑星環境をゲームの中心的要素に昇格させる。

---

## 現状の課題

| 課題 | 現行の挙動 |
|------|-----------|
| 惑星の均質性 | 全惑星が人口無限増加可能、キャパシティなし |
| 環境の静的さ | 産出量は初期値のままで変化しない |
| テラフォーミング不可 | 惑星を変化させる手段がない |
| 立地の意味なし | 「どの惑星に生まれたか」の戦略的差異が小さい |

---

## 設計

### 1. 惑星環境コンポーネント

```rust
/// 惑星の物理的・環境的特性（Planet エンティティに付与）
#[derive(Component, Debug, Clone)]
pub struct PlanetaryEnvironment {
    // === 基本物理 ===
    /// 惑星質量（地球 = 1.0）
    pub mass: f64,
    /// 表面重力（地球 = 1.0G）— 建造効率に影響
    pub gravity: f64,
    /// 惑星半径（地球 = 1.0）— 居住可能面積に影響
    pub radius: f64,

    // === 大気・気候 ===
    /// 大気組成タイプ
    pub atmosphere: AtmosphereType,
    /// 大気圧（地球 = 1.0 atm）
    pub atmospheric_pressure: f64,
    /// 平均気温（℃）
    pub temperature: f64,
    /// 水の存在率（0.0 ~ 1.0）
    pub water_coverage: f64,

    // === 居住性 ===
    /// 総合居住性スコア（0.0 ~ 1.0、各要素から計算）
    pub habitability: f64,
    /// 最大人口キャパシティ（居住性 × 面積から算出）
    pub population_capacity: f64,

    // === 環境リスク ===
    /// 放射線レベル（0.0 = 安全, 1.0 = 致死的）
    pub radiation: f64,
    /// 地殻活動レベル（0.0 = 安定, 1.0 = 超活発）
    pub tectonic_activity: f64,
    /// 隕石衝突リスク（0.0 ~ 1.0）
    pub meteorite_risk: f64,

    // === 資源 ===
    /// 鉱物埋蔵量（有限）
    pub mineral_deposits: f64,
    /// 鉱物の採掘しやすさ（0.0 ~ 1.0）
    pub mineral_accessibility: f64,
    /// 再生可能エネルギー適性（太陽光、風力等）
    pub renewable_energy_potential: f64,
    /// 土壌肥沃度（0.0 ~ 1.0, 農業で変動）
    pub soil_fertility: f64,
}

/// 大気組成の分類
#[derive(Debug, Clone, Copy, PartialEq)]
pub enum AtmosphereType {
    /// 地球型（O₂/N₂ — 呼吸可能）
    EarthLike,
    /// CO₂ 主体（金星型 — テラフォーミング必要）
    CarbonDioxide,
    /// 希薄大気（火星型）
    Thin,
    /// 有毒（H₂S, NH₃ 等）
    Toxic,
    /// なし（月型）
    None,
}
```

### 2. 居住性の計算式

```
habitability = 大気スコア × 重力スコア × 気温スコア × 水スコア × 放射線スコア

大気スコア:
  EarthLike      → 1.0
  CarbonDioxide  → 0.2 （テラフォーミングで改善可能）
  Thin           → 0.4
  Toxic          → 0.05
  None           → 0.01 （ドーム都市のみ）

重力スコア:
  0.8 ~ 1.3G → 1.0
  0.5 ~ 0.8G → 0.8
  1.3 ~ 2.0G → 0.7
  それ以外   → 0.3

気温スコア:
  -10 ~ 40℃ → 1.0
  -40 ~ -10 or 40 ~ 60 → 0.6
  それ以外   → 0.2

水スコア:
  >= 0.3 → 1.0
  0.1 ~ 0.3 → 0.7
  < 0.1 → 0.3

放射線スコア:
  < 0.2 → 1.0
  0.2 ~ 0.5 → 0.7
  > 0.5 → 0.3

population_capacity = habitability × radius² × 50,000,000
```

### 3. 環境が各システムに与える影響

| システム | パラメータ | 影響 |
|---------|-----------|------|
| **経済** | 重力 | 重力 > 1.3G で工業効率 -20%、低重力で建造コスト -10% |
| **経済** | 土壌肥沃度 | 食料産出に乗算（0.0 ~ 1.5） |
| **経済** | 再生可能ｴﾈﾙｷﾞｰ適性 | エネルギー産出に加算ボーナス |
| **人口** | 居住性 | 人口キャパシティの決定 |
| **人口** | 放射線 | 人口成長率にペナルティ |
| **人口** | 気温の極端さ | エネルギー消費量が増加（冷暖房需要）|
| **軍事** | 重力 | 高重力惑星は防御に有利（着陸戦ペナルティ） |
| **イベント** | 地殻活動 | 地震イベントの発生確率に影響 |
| **イベント** | 隕石リスク | 隕石衝突イベントの発生確率 |

### 4. テラフォーミングシステム

テラフォーミング技術をアンロックした国家は、惑星環境を段階的に改善できる。

```
テラフォーミングプロセス:
  Phase 1: 大気密度の調整     — 500 エネルギー/Tick × 50 Tick
  Phase 2: 温室効果ガス制御   — 300 エネルギー/Tick × 30 Tick
  Phase 3: 水の液化・配布     — 200 エネルギー + 100 工業品/Tick × 40 Tick
  Phase 4: 生態系の植え付け   — 100 食料 + 50 工業品/Tick × 60 Tick

各フェーズの完了で:
  大気 → EarthLike に段階的に移行
  気温 → 20℃ に漸近
  水 → 0.5 に漸近
  居住性 → 再計算

テラフォーミングコスト合計: 膨大なエネルギーと工業品
→ 核融合技術が事実上の前提条件
```

### 5. 初期惑星環境の設定

| 惑星 | 質量 | 重力 | 大気 | 温度 | 水 | 放射線 | 居住性 | 人口上限 |
|------|------|------|------|------|-----|--------|--------|---------|
| 地球 | 1.0 | 1.0G | EarthLike | 15℃ | 0.71 | 0.05 | 0.95 | ~4750万 |
| プロキシマb | 1.3 | 1.1G | CarbonDioxide | -20℃ | 0.15 | 0.45 | 0.08 | ~540万 |
| シリウスIII | 0.8 | 0.9G | Thin | 5℃ | 0.30 | 0.10 | 0.32 | ~1200万 |

## 期待される効果

1. **惑星の個性**: 同じ「資源豊富」でも重力が高い・放射線がある等のトレードオフ
2. **長期目標**: テラフォーミングが数百Tickの壮大なプロジェクトになる
3. **戦略的ジレンマ**: 「厳しい環境だが資源が豊富な惑星を開拓するか？」
4. **環境のダイナミクス**: テラフォーミングで惑星が変わっていく過程がドラマチック
