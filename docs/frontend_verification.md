# フロントエンド検証ガイド

本プロジェクトのWebフロントエンド (`web/`) は、Rustバックエンド (`src/`) とWebSocketで通信し、シミュレーション状況を可視化します。
開発中の動作確認および統合テストを行う際の手順を以下に示します。

## アーキテクチャ概要

- **Backend (Rust)**: `0.0.0.0:8080` でWebSocketサーバーを起動し、Tickごとにシミュレーション状態（JSON）をブロードキャストします。
- **Frontend (React)**: `ws://localhost:8080` に接続し、受信したデータをストア (`useSimulationStore`) に反映して描画します。

## 検証手順

WebUIとバックエンドの連携を確認するには、以下の手順でそれぞれを起動してください。

### 1. バックエンドの起動 (Headless Mode)

バックエンドを「UIなし（Headless）」かつ「無限Tick」モードで起動します。これにより、バックエンドは計算とWebSocket送信に専念します。

```bash
# プロジェクトルートディレクトリで実行
cargo run -- --max-ticks -1
```

> [!NOTE]
> `--max-ticks -1` を指定しない場合、デフォルトの設定（例: 50 ticks）でシミュレーションが終了してしまい、フロントエンドでの確認が困難になります。

正常に起動すると、以下のようなログが表示されます：

```text
WebSocket Integration Server listening on ws://0.0.0.0:8080
```

### 2. フロントエンドの起動

別のターミナルを開き、フロントエンド開発サーバーを起動します。

```bash
cd web
npm run dev
```

### 3. ブラウザでの確認と接続

1. ブラウザで `http://localhost:5173` (Viteのデフォルトポート) にアクセスします。
2. **モード切替**:
   初期状態では、フロントエンドは **「MOCK」** モード（内部データによるデモ表示）で動作しています。
   画面右上の **「MOCK」** ボタンの隣にある **「LIVE」** ボタンをクリックしてください。

   - **LIVE ボタンが赤く点灯**: バックエンドとのWebSocket接続が有効化されました。
   - **画面の更新**: バックエンドのTick進行に合わせて、日付（Tick数）やマップ上の艦隊の動きが同期されます。

### トラブルシューティング

**Q. LIVEにしても何も動かない**
- バックエンドが起動しているか確認してください。
- ブラウザのコンソール (`F12` -> Console) にWebSocket接続エラーが出ていないか確認してください。

**Q. データがおかしい（Tickが0のままなど）**
- バックエンドの修正が反映されているか確認してください（`cargo run` で再ビルドされます）。
- *Note: 以前のバージョンではTickが0に固定されるバグがありましたが、修正済みです。*
