# events — ランダムイベント

**ファイル**: `src/systems/events.rs`  
**関数**: `event_system`  

## 概要
惑星ごとに一定の確率でランダムなイベントを発生させます。これらのイベントは決定論的に判定され、同じシード値であれば完全に再現されます。

## アルゴリズムの概要

1. **発生判定**:
   - `seed × tick × planet_index` のハッシュ値を計算し、それに基づいてイベントの発生有無を決定する。

2. **種類の選択（加重抽選）**:
   - 惑星の現在の状態（地殻活動、放射線レベル、汚染度など）により、特定のイベントが発生しやすくなる補正（ウェイト）を計算。
   - ウェイトに基づき、発生するイベントを選択。

3. **効果の適用**:
   - 人口の増減、資源の増減、研究ポイントの付加などの効果を惑星または国家に適用。

詳細なイベント一覧と効果値は [balance.md](../balance.md) を参照してください。

## 主なイベントの種類
- **環境災害**: 地震、放射線嵐、隕石衝突（これらは惑星の物理パラメータに依存）。
- **社会イベント**: 疫病、ベビーブーム、反乱。
- **経済・技術イベント**: 豊作、鉱脈発見、技術ブレイクスルー。
- **特殊**: 汚染が深刻な場合に発生する「大規模環境災害」。

## 設計メモ
- イベントはプレイヤーに対する一時的なチャンスまたはリスクとして機能し、静的な経済成長に変化を与える。
- 発生判定にハッシュを使用することで、シミュレーションがマルチスレッドで実行されても「いつ、どこで何が起きるか」の決定論性が保たれる。
