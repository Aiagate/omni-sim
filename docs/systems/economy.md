# economy — 資源産出・消費

**ファイル**: `src/systems/economy.rs`  
**関数**: `resource_production_system`  

## 概要
惑星の人口、技術レベル、環境状態に基づいて資源を産出し、維持コストとして資源を消費します。また、生産活動に伴う環境汚染の発生も管理します。

## アルゴリズムの概要

1. **ボーナスの計算**:
   - 人口規模による労働力ボーナスを計算。
   - 分野別の技術レベルによる技術ボーナスを適用。

2. **資源の産出**:
   - **食料**: 土壌肥沃度の影響を受ける。
   - **鉱物**: 埋蔵量による制限と、採掘深度によるペナルティを受ける。
   - **エネルギー**: 核融合技術によるボーナスと、再生可能エネルギー出力の影響を受ける。
   - **工業品**: 重力ペナルティとレアアースの利用効率の影響を受ける。

3. **汚染の発生**:
   - 工業生産および化石燃料の消費に応じて大気汚染が発生。
   - 鉱物採掘に応じて水質汚染が発生。

4. **資源の消費**:
   - 人口に応じた食料消費。
   - 人口および惑星気温に応じたエネルギー消費。
   - 工業生産に応じた鉱物およびレアアースの消費。

詳細な数式やバランス定数は [balance.md](../balance.md) を参照してください。

## 環境ダイナミクス
`resource_production_system` の後に、以下の処理を行う `environment_dynamics_system` が実行されます。
- 汚染の自然浄化。
- 環境技術による浄化ボーナスの適用。
- 土壌の劣化と回復。

## 設計メモ
- **資源枯渇**: 鉱物資源と化石燃料には有限の埋蔵量がある。
- **採掘深度**: 掘進が進むにつれペナルティが発生し、採掘効率が低下する。
- **化石燃料依存**: 核融合技術の研究により、エネルギー生産における化石燃料への依存度を低減できる。
