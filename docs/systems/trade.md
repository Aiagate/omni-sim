# trade — 星間貿易

**ファイル**: `src/systems/trade.rs`  
**関数**: `trade_system`  

## 概要
惑星間の貿易ルートを通じて、余剰資源の融通を行います。輸送には星間距離に応じたコストと時間が考慮されます。

## アルゴリズムの概要

1. **輸送コストの算出**:
   - 貿易ルートの距離に基づき、資源の消失率（輸送コスト）を決定する。

2. **余剰判定**:
   - 輸出側の在庫が輸入側に対して一定以上の差（余剰閾値）がある場合に貿易が発生する。

3. **資源の移動**:
   - ルートの最大輸送容量（capacity）と輸出側の在庫上限を考慮して、実際の輸送量を決定する。
   - 輸送された資源の一部はコストとして消失し、残りが輸入側に届く。

詳細な数式やバランス定数は [balance.md](../balance.md) を参照してください。

## 星系間距離の目安
- **Sol ↔ Alpha Centauri**: 近距離。低コストで活発な貿易が可能。
- **Sol ↔ Sirius**: 中距離。輸送コストが無視できないレベルになる。
- **Alpha Centauri ↔ Sirius**: 中距離。

## 設計メモ
- 貿易は資源の偏り（特化惑星と消費惑星）を解消する重要な手段である。
- 距離コストは、遠方の植民地を維持する難易度を表現している。
