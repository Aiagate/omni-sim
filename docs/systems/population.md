# population — 人口増減

**ファイル**: `src/systems/population.rs`  
**関数**: `population_growth_system`  

## 概要
食料の充足率、惑星の居住性、および環境汚染の影響を考慮して、惑星の人口を増減させます。

## アルゴリズムの概要

1. **食料の影響**:
   - 食料が充足している場合、基本成長率にボーナスが加算される。
   - 食料が不足（飢餓）している場合、不足度合いに応じた減少ペナルティが発生する。

2. **環境の影響**:
   - 放射線レベルが高いほど、成長率にペナルティが発生する。
   - 大気・水質汚染による健康被害（health penalty）が成長率を直接低下させる。

3. **キャパシティ制限**:
   - 人口が惑星の最大収容力（population capacity）に近づくと、成長率が急激に鈍化する。
   - 最大収容力を超えて人口が増えることはない。

詳細な数式やバランス定数は [balance.md](../balance.md) を参照してください。

## 設計メモ
- **居住性 (Habitability)**: 大気、重力、気温、水、放射線などの環境パラメータから算出され、人口キャパシティを決定する。
- **健康被害**: 汚染は単なる環境スコアの悪化ではなく、人口増加そのものへの直接的な脅威として機能する。
